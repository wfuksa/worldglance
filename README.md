# Worldglance

Worldglance is an interactive, stylized simulation of the living Earth.

The goal is to let a user explore the planet and see a world that feels active: cities, roads, vehicles, aircraft, ships, weather and major events.

Worldglance should feel somewhere between an interactive globe, a living map and a calm simulation.

The project begins with the website.

Mobile applications may be developed later after the website and its core technology are proven.

## Development philosophy

Worldglance should be built iteratively.

The normal development loop is:

idea -> build -> run -> inspect -> improve -> test -> GitHub -> continue

We prefer working prototypes over extensive speculative planning.

Architecture should become more sophisticated only when the product actually requires it.
